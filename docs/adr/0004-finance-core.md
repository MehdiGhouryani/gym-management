# ADR ۰۰۰۴ — هسته مالی نسخه ۲

وضعیت: پذیرفته‌شده | تاریخ: ۱۴۰۵/۰۹/۲۹

## بازپرداخت با سند معکوس

- بازپرداخت (`Refund`) سند جداگانه است؛ هیچ پرداختی حذف یا ویرایش نمی‌شود.
- در سطح پایگاه داده هم `payments` و `refunds` برای نقش برنامه **append-only**‌اند (REVOKE UPDATE/DELETE در `000_app_role.sql`).
- سقف بازپرداخت: پول خالص پرداخت‌شده‌ی عضو (Σپرداخت − Σبازپرداخت). مانده‌ی منفی ممنوع (قید DB هم دارد).
- **اشتراک لغوشده از محاسبه‌ی بدهی کنار می‌رود** — نتیجه: جریان درستِ «لغو اشتراک + بازپرداخت وجه» مانده را صفر می‌کند.
- بازپرداخت فقط مدیر (`OWNER`) است و در لاگ ممیزی ثبت می‌شود (`payment.refund`).

## درآمد گزارش‌ها

- درآمد ماه = پرداخت‌های دریافتی همان دوره (به وقت تهران) **منهای بازپرداخت‌های همان دوره**.
- همین قاعده در داشبورد و روند ۶ ماه اعمال شده تا همه‌ی اعداد یک منبع داشته باشند.

## جستجوی تراکنش

- فهرست پرداخت‌های باشگاه (`GET /payments`، فاز ۹) با بازه‌ی روز تهران و جستجوی نام/شماره — مرز روزها با `+03:30` دقیق است.

## رسید

- برای MVP رسید = ردیف پرداخت با شناسه‌ی یکتا و تاریخ ممیزی؛ چاپ/PDF رسید و اسناد در فاز ۲۱ (خروجی‌ها) می‌آید تا فایل اضافه ساخته نشود.
